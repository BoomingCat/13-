# 基础架构说明

## 请求链路

```text
Vue 工作台
  -> FastAPI /api/v1/analysis/query
  -> Agent 任务规划
  -> 业务知识与元数据检索
  -> SQL/Python 生成
  -> 安全校验及隔离执行
  -> 图表与结论生成
  -> 返回前端
```

## 存储职责

- PostgreSQL：制造业务数据、平台数据、指标口径、任务记录。
- pgvector：指标、表和字段说明的语义向量。
- Redis：任务状态、缓存和异步队列。
- MinIO：导入文件、报告、图表和模型文件。

## 安全边界

- Agent 查询账号只能读取业务 Schema。
- SQL 必须经 AST 校验、表字段白名单、超时和行数限制。
- Python 建模应通过预定义工具或独立容器运行。
- 所有生成语句、执行步骤和异常均写入审计记录。
